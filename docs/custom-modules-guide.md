# 自定义模块功能使用说明

## 功能概述

自定义模块允许用户创建个性化的AI内容展示模块，支持两种类型：

### 1. 生成文字类型（text）

类似"每日小知识"功能，AI根据提示词生成简洁的文字内容。

**使用场景：**

- 每日编程小知识
- 技术Tips分享
- 行业资讯摘要
- 学习心得记录

**提示词示例：**

```
请分享一个有趣的JavaScript小技巧，控制在80字以内
```

```
今天的前端开发最佳实践是什么？请用简洁的语言说明
```

### 2. 数据排行类型（ranking）

AI分析并生成结构化的排行榜数据，以JSON格式输出，页面会自动解析并以列表形式展示。

**使用场景：**

- 技术栈流行度排行
- 工具/框架对比排行
- 行业趋势分析
- 市场调研数据

**提示词要求：**
必须要求AI输出JSON格式，包含以下结构：

```json
{
  "rankings": [
    {
      "title": "榜单标题",
      "items": ["项目1", "项目2", "项目3"]
    }
  ]
}
```

**提示词示例：**

```
获取当前国内的开发语言技术栈排行：
1.明确排行的应用场景：了解宏观的市场趋势
2.聚焦的行业或技术领域：前端开发 （JavaScript / TypeScript ，vue/react/angular 等）
3. 偏好的数据来源或榜单：招聘平台数据

请以JSON格式输出，包含多个维度的排行榜。
```

```
分析当前最流行的CSS框架，包括Tailwind CSS、Bootstrap等，按受欢迎程度排序。
输出JSON格式，每个榜单包含title和items字段。
```

## 使用步骤

### 1. 添加新模块

1. 在"其他工具"页面找到"自定义模块"卡片
2. 点击右上角的"+"按钮
3. 填写模块信息：
   - **模块名称**：给模块起个名字（如："前端技术栈排行"）
   - **模块类型**：选择"生成文字"或"数据排行"
   - **提示词**：输入详细的提示词，告诉AI你想要什么内容

### 2. 编辑模块

- 点击模块卡片右上角的"编辑"图标（铅笔图标）
- 修改模块名称、类型或提示词
- 点击"保存"确认修改

### 3. 删除模块

- 点击模块卡片右上角的"删除"图标（垃圾桶图标）
- 模块将被立即删除

### 4. 刷新内容

- 点击模块卡片右上角的"刷新"图标（星星图标）
- AI会重新生成最新的内容
- 如果AI未配置或未启用，会显示错误提示

## 注意事项

### 排行榜类型的特殊要求

1. **JSON格式要求**：提示词中必须明确要求AI输出JSON格式
2. **数据结构**：必须包含`rankings`数组，每个元素有`title`和`items`字段
3. **容错处理**：如果AI输出的JSON解析失败，会以纯文本形式展示原始内容

### 性能优化

- 模块内容会被缓存，不会每次打开都重新请求
- 点击"刷新"按钮可以强制重新生成内容
- 流式输出，内容会逐步显示，提升用户体验

### AI配置要求

使用前需要：

1. 在"全局设置"中启用AI功能
2. 配置Base URL（API地址）
3. 配置API Key
4. 配置Model（模型名称）

## 常见问题

### Q: 为什么排行榜没有正确显示？

A: 检查提示词是否明确要求AI输出JSON格式，以及JSON结构是否正确。

### Q: 内容生成很慢怎么办？

A: 这是正常现象，AI需要时间思考和生成内容。可以尝试简化提示词或选择更快的模型。

### Q: 如何获得更好的排行榜结果？

A:

- 提供清晰的背景信息和数据来源要求
- 明确排行的维度和标准
- 要求AI按照指定格式输出
- 可以举例说明期望的输出格式

### Q: 可以创建多少个模块？

A: 理论上没有限制，但建议保持合理的数量以避免性能问题。

## 高级技巧

### 1. 组合使用

可以同时创建多个不同类型的模块，比如：

- 一个"每日编程Tip"（text类型）
- 一个"前端框架排行"（ranking类型）
- 一个"行业资讯"（text类型）

### 2. 动态提示词

虽然目前不支持变量替换，但你可以在提示词中包含通用描述，让AI自行判断当前情况。

### 3. 多榜单展示

ranking类型支持在一个模块中展示多个相关榜单，只需在JSON的rankings数组中添加多个元素即可。

## 技术实现

- **后端**：使用Electron IPC通信，调用AI API进行流式生成
- **前端**：Vue 3组件，支持实时内容更新和状态管理
- **数据存储**：模块配置保存在应用设置中，内容缓存在内存中
- **JSON解析**：自动尝试从AI输出中提取JSON格式的排行榜数据
